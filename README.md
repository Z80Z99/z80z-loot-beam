# Loot Beams Lite

Minecraft 1.20.1 Forge 客户端模组：为掉落物显示按稀有度着色的光柱、光晕、名称与物品提示框。
无第三方前置，兼容原版渲染，也针对光影包做了专门处理。

## 特性

- 7 种光柱样式：经典光柱、纤细激光、柔光雾柱、锥形尖塔、螺旋光带、双螺旋、浮空光环
- 颜色跟随稀有度（普通白 / 少见绿 / 稀有蓝 / 史诗粉 / 附魔紫），也可按物品、标签、模组自定义
- 光柱淡入、近距离淡出、顶端渐隐；普通品质可缩短光柱；动态呼吸与旋转动画
- 地面光晕与光环，半径独立可调
- 掉落物名称：颜色跟随光柱、可显示堆叠数量、背景边框、缩放与偏移，可限制"仅准星看向时显示"
- 潜行看向掉落物时显示完整物品提示框
- 新掉落物提示音，带独立声音黑名单
- 图形配置界面支持中文 / 英文（跟随客户端语言），每个设置都有悬停说明
- 筛选：白名单 / 黑名单（物品、标签、模组）、仅装备、仅稀有品质、最大渲染距离
- 性能：按掉落物缓存规则与名称、每帧单次遍历、视锥剔除、距离平方比较

## 环境

- Minecraft 1.20.1
- Forge 47.3.0 或更高
- 仅客户端安装（服务器不需要装）

## 安装

把 `loot-beams-lite-forge-1.20.1-<版本>.jar` 放进 `.minecraft/mods`。

## 使用

- 游戏内按 `B` 即时开关光效
- 模组列表 → Loot Beams Lite → 配置，打开图形界面（每个设置悬停都有说明）
- 配置文件：`config/lootbeamslite-client.toml`

## 从源码构建

需要 JDK 17：

```bash
./gradlew build
```

产物位于 `build/libs/loot-beams-lite-forge-1.20.1-<版本>.jar`。

## 渲染说明

- **关光影**：自建渲染类型配原版位置-颜色着色器，加色混合绘制同心光壳与地面光环。
- **开光影**：光影包会接管世界着色器。通用方块程序会把光柱漂白并抖动低透明度像素，信标光柱程序会把颜色平方后交给光照阶段（变黑），闪电程序会直接覆盖顶点色。因此光柱改走光影包的**粒子通道**：所有渐变量放进渐变贴图（贴图 UV 在所有程序里都是平滑插值的），顶点 alpha 固定为 1、贴图颜色略偏离纯白，避免被识别为烟雾 / 雪 / 岩浆粒子改写颜色。
